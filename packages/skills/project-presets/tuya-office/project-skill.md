# Tuya Office Report Method

Read the current manifest, published project-configuration.json and project-context.md. Apply the versioned energy-report-investigation and tuya-report-composition references supplied in skill-references.json, together with the shared report-presentation.md when present. Project facts and assumptions live in project context, not in this method.

For each window, explore and rank candidates, cluster overlapping findings by the decision they support, retain the strongest 2–3 questions, and summarize 3–4 short conclusions first (fewer if warranted). Remove low-value repetition without imposing a word cap or reducing useful evidence. Prior reports and notes are comparison evidence only when actually supplied. New data may reverse earlier findings; stability and verified improvement are valid outcomes.

Save English HTML, computed facts and exploration notes. Propose reusable improvements as a Skill draft rather than automatically changing the accepted method. Do not carry forward old measured numbers, source attachment names or unconfirmed project assumptions as fixed requirements.
