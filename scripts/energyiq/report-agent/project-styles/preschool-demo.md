# Preschool portfolio visual identity

Appearance reference: the supplied Preschool Energy Analysis Report, May 2026. Recompute all content from the selected project data; the reference supplies appearance only.

- Light #f0f2f5 canvas and white evidence panels. Dark blue masthead using #1a1a2e, #16213e and #0f3460, with white readable text; blue #2980b9 is the primary chart accent.
- System/Segoe UI sans-serif, body around 16px and line-height 1.6. Main content approximately 1240px wide with 24px gutters. Heading hierarchy, rather than explanatory microcopy, should organize the page.
- Put the period's concise conclusions directly after the compact masthead and before detailed evidence. A compact horizontal section navigation is optional when the report needs it; keep it below the opening findings.
- Use lightly rounded white chart panels, subtle shadows and clear section titles. Present portfolio comparisons, centre rankings and drill-down evidence in generous charts with adjacent numbers. Use two columns only when labels remain readable; stack on mobile.
- Blue, green, orange and muted red can distinguish measured series and findings; always supply labels, units and text alternatives. Tables have a pale header row and right-aligned numeric columns.
- Preserve the blue portfolio identity while changing analytical questions and section content to fit current evidence. Do not adopt another project's orange editorial identity because a shared method or previous example used it.

Deliver offline HTML; reference CDN dependencies are not delivery requirements. Verify desktop and 390px layout, numeric/filter consistency and print readability. New style versions need explicit project activation; analysis updates preserve the current style.
