# 日级能源分析与 AI 问数 MVP 需求确认稿

> 甲方已确认本文的核心业务需求与目标一致。后续内部讨论增加了 Project Explorer、动态 Tier、虚拟表、Interactive Analysis 和 Admin 发布流程，这些是实现与运维深化，不改变本文“日级同步、时间段分析、模板复跑、AI 问数和可追溯”的外部需求。Interactive Analysis 允许用户切换时间即时查看；只有保存分析、生成报告或定时报告才形成正式 Analysis Run。当前完整规格见[新会话入口](../decisions/当前共识与新会话入口.md)。

## 1. 建设目标

首期只交付两个客户功能：

1. **分析报告**：用户选择时间段，系统使用固定结构化模板即时生成该时间段的能源分析；需要留档时保存为正式运行记录以便复跑。
2. **AI 问数**：用户用自然语言询问能源数据，系统返回文字、表格或图表，并提供 SQL、指标和数据来源。

系统每天从 Tuya API 同步一次数据。首期不追求实时看板，也不允许 AI 直接修改正式模板。

## 2. 客户主流程

```text
每日 Tuya 数据同步
→ raw 数据清洗与累计读数差分
→ 规范化能源事实
→ Interactive Analysis：选择时间段并即时刷新固定模板
→ 可选保存分析/生成报告
或
→ AI 问数：提问并查看带来源的回答
```

## 3. MVP 功能

### 3.1 每日数据同步

- 每个 Workspace 配置独立的 Tuya 数据源。
- 每天执行一次增量同步，处理认证、分页、限流、重试和幂等。
- 保存同步状态、数据覆盖时间、最后成功时间和错误原因。
- 保留 raw 数据，并生成规范化的15分钟能耗、平均功率和日级聚合。

### 3.2 分析报告

- 默认提供“昨天、最近7天、最近30天、自定义日期”。
- 自定义日期按客户 Workspace 时区解释为完整自然日。
- 固定报告至少展示总耗电量、日均耗电量、峰值平均功率、数据完整率、每日趋势、楼层对比、回路构成和异常数据。
- 普通时间切换即时刷新，不自动制造 `Analysis Run`；用户保存分析、生成报告或系统执行定时报告时才保存正式 Run。
- 模板当前由我方人工维护；普通用户不看到模板编辑器。

### 3.3 AI 问数

- 用户可询问指定时间段内的楼层、设备、回路、工作日/周末和异常用电。
- 回答可包含文字、KPI、表格和图表。
- 支持同一会话内继续追问。
- 每个关键数字可展开查看 SQL、指标、时间段、设备范围和数据版本。
- 首期不支持把 AI 回答添加到分析报告或保存为新模板。

### 3.4 模板复跑与未来 AI 修改

- 模板保存分析定义，不保存某一次结果截图。
- Interactive Analysis 只改变运行参数，不改变模板和指标口径；正式保存时绑定模板版本、时间段、数据快照和指标版本。
- 首期只支持人工维护模板；用户可自由切换时间查看，并可把需要留档的结果保存后复跑。
- 架构预留 AI 生成 `Template Change Proposal`；未来经过校验、预览和人工确认后，才创建新的 `Template Revision`。

### 3.5 Workspace 与账号

- 一个物业、便利店、Preschool 或养老院等客户单位对应一个 Workspace。
- 第一阶段允许一个 Workspace 只有一个账号。
- 账号和 Workspace 分开建模，为未来多账号协作预留 Membership。
- 设备、数据、指标和已发布报告属于 Workspace；Chat、草稿和未发布内容默认属于个人。
- Tuya 合作方可在后续管理下属 Workspace 的账号与运行状态，但不默认读取客户业务数据。

## 4. MVP 不包含

- 5分钟或秒级实时数据；
- 客户自行拖拽编辑看板；
- AI 直接修改或自动发布模板；
- Superset、Rill 等独立 BI 看板平台集成；
- 多 Agent 自主协作；
- 设备控制、规则引擎和告警下发；
- 复杂跨 Workspace 分享和用户级 ACL；
- Partner 管理后台。

## 5. 验收场景

1. 每日同步成功后，页面显示最新数据时间和同步状态。
2. 累计 `Active Energy` 被正确转换为区间耗电量，负数、重复时间、缺口和异常跳变不会静默进入结果。
3. 用户选择昨天或自定义日期范围后，固定结构分析自动刷新且不产生无意义运行记录。
4. 同一模板更换时间段时结构和指标口径保持一致；保存为正式 Run 后可按相同版本复跑。
5. AI 能回答至少三类能源问题，并生成表格或图表。
6. 结构化报告和 AI 回答对同一指标、同一时间段给出一致数字。
7. 结果可追溯到 SQL、指标、时间段、设备范围、模板版本和数据快照。
8. Workspace A 无法读取 Workspace B 的数据、报告、会话或同步记录。
9. 数据尚未更新、同步失败或期间不完整时，页面明确提示，不展示“假最新”。
