# 主流程联调：初始化、自动取数、报告与 Skill 复跑

## 当前执行范围

只推进资料/API/CSV → 项目初始化与可读配置 → 自动取数 → 对话报告 → Skill Creator → 新时间窗口自动报告。单份报告追问、通用 BI 等扩展不阻塞本轮。

## 已核实与新改动

1. 初始化：Agent 可读取材料并保存结构/映射草稿、独立项目说明，配置页可读展示；营业日历/电价保存为未激活版本。完整发布/激活工作流仍需联调，不能把保存草稿称为完成上线初始化。
2. API 自动更新：2026-09-12 只读核实线上 SQLite，最近七次 scheduled source sync 均 succeeded，最后成功为 2026-09-11T17:00:10.298Z（新加坡9月12日01:00），水位1789142400000。线上日志同一时段的 failed 是后续旧分析预热的完整日校验错误，不能用单行日志断言取数失败。当前本地调度器已有独立 after-publication-failed 日志与测试，线上旧 Release 未更新。
3. 每次报告输入新增 project-configuration.json：包含已发布层级、计量归属、正式日历/电价及数据/配置版本；与 project-context.md、project-skill.md 一并记录哈希。保存中的草稿与未激活策略不能覆盖正式规则。输入准备期间版本变化则要求重试。
4. 真实服务复跑在 SQLite 备份和独立 DuckDB 副本上执行，避免覆盖 Charles 的现有报告、设置与 Skill。独立副本使用真实项目数据，测试周期内不会自动获取新的线上数据。

## 验收边界

- 技术验收：真实数据报告 → 实际对话提取 Skill → 调度器选取不同日期 → 读取同一 Skill 与重新导出的数据 → 独立 HTML。
- 价值验收：Charles 确认分析角度、事实解释与视觉呈现符合需要。此项不能由 Agent 自行标记通过。
- 上线验收：部署后核对取数、发布、报告调度、失败状态、重复触发和权限。当前本地测试不代表生产已上线。

## 待完成
