# Agent 年度收益计算验收

关联任务：#248，T03/T04/T08。状态：本地实现与基础测试通过；真实模型首轮数据核对通过、收益表达尚不通过。未发布客户首页。

## 本轮实现

- Agent 自选方法并在沙盒执行计算，系统不再规定按日型乘全年天数的唯一公式。
- 候选可携带 annualBenefit：年范围、可选货币范围、方法、条件、假设、脚本和结果文件。缺电价可仅提供 kWh，缺关键资料可不量化。
- 发布时检查脚本/JSON 为有限大小普通文件、路径受限、结果与候选一致；保存进原有不可变 Key Points 发布版本，服务端只格式化金额。
- 文件存在/内容一致不等于计算正确或确实执行；计算与假设仍需独立审阅。API 主机不执行模型代码。行动详情完整展示、HTML 数字一致性仍待接通验收。
- 20 项相关测试通过，API TypeScript 构建通过。未生产部署。

## 未通过项与修正
