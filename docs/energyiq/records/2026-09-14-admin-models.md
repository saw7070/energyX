# Admin Models：配置、测试与切换验收

日期：2026-09-14。关联：#244。

## 行为

Admin 新增直接可见的 Models 入口。顶部显示服务器当前生效的模型，作用于所有项目的 Pi 对话、报告、审阅与 Skill 提取。它不依赖选中项目的配置是否已经完成。

添加配置需要名称、模型 ID、HTTPS API base URL、API key。首版仅支持报告运行器已经接通的 OpenAI-compatible Chat Completions。密钥由现有 secrets 存储加密保存，响应不返回密钥。修改 key 或地址通过新增候选完成，不直接编辑生效配置。

保存、测试、启用分离。测试进行两次小请求，验证流式工具调用、工具结果回传与后续文本；不发送项目资料。DeepSeek 思考模式拒绝强制 tool_choice，因此与实际运行对齐，采用 auto，并保留 reasoning_content 以完成工具续接。

启用必须满足测试指纹匹配、配置版本与默认绑定版本一致。使用现有 config_resources/model-profile 和 workspace_default_model_profiles，不新建平行模型存储。其他管理员可看到当前默认，但不能读取、测试或启用不属于自己的私有配置。

正在运行的 Pi harness 已捕获模型配置，不受切换影响。尚未开始的任务（包括队列里的任务）在执行时读取新默认。当前未实现排队时冻结模型；页面已明确该行为。Skill 的冻结规则与模型的读取时机不要混淆。
