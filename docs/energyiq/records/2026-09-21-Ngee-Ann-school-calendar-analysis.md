# Ngee Ann 学校假期分析要求与验收

## 已确认的产品要求

学校项目不能只比较 weekday/weekend/public holiday。完整报告还需要学校假期与正常教学期的用电量、日内曲线、使用模式及主要回路差异。方法放在可复用分析 Skill；具体校历、范围、设备身份保留在项目已发布配置。不会把学校假期当成停业、不会新增一份独立日历副本。

日期分类有三个独立维度：星期几、是否公共假日、学期阶段。学校假期包含 term_break/vacation；study_exam 单列，不等同于正常上课。一个周日也可以同时是公共假日和学校假期。

## 可复用方法

1. 读取项目校历，为读数添加三个分类维度；无校历日期保持未知，不自行推断。
2. 先用完整、非公共假日的星期一至五，对比学校假期与前后教学期。展示日期、样本数、均值/中位数；控制星期构成差异。
3. 输出同口径 24 小时曲线和各小时样本数；关注早间启动、白天负荷、晚间/夜间及停机时点。
4. 按楼层和回路解释主要差异，避免父子电表重复求和。保留周六、周日与公共假日的独立视图及小样本说明。
5. 将事实与假设分开。资料不足时提出关键现场问题，不直接判定浪费、危险或可节省电量。
6. 报告保留有解释价值的发现，不强制每项比较进入六个行动槽位。

实装：energy-report-investigation 0.8.0、report-presentation 1.7.0、report-review 0.6.0。呈现方法是现有 report-inputs 自动写入的共享输入；当前仅修改代码库版本，未部署或修改线上默认绑定。
