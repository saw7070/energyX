# 2026-08-01 开发记录：Ngee Ann 源到事实契约原型

## 1. 目标与范围

本轮只回答一个问题：**Excel 当前接入与 Tuya API 未来接入，能否在数据源之后共用同一套可追溯事实、质量、虚拟表和官方汇总逻辑？**

验证范围：

- 读取两份真实 Ngee Ann Level 6 Excel；
- Excel Source Binding 使用已确认的完整 `Device Name`；
- 累计读数转换为保留实际时长的 Interval Fact；
- 重叠批次确定性选取规范读数，同时保留冲突证据；
- 计算 `Virtual Load 12 = Load 1 + Load 2`；
- 证明 Virtual Meter 默认不进入官方总量；
- 用合成边缘场景运行 gap、reset、冲突和缺失输入规则。

本轮不实现数据库迁移、Admin 页面、正式 Tuya Connector、通用公式解析器或生产发布流程。

### 2.1 统一 Adapter 输出

Excel 与 Tuya 只负责产生同一种 Import Batch：

~~~text
Import Batch
├── batchId / sourceKind / sourceId
├── artifactSha256 / coverageEnd
└── Raw Reading[]
    ├── stableSourceKey
    ├── sourceLabel
    ├── observedAt / cumulativeValue / unit
    └── sourceRef
~~~

稳定来源键：

- Excel：`excel:<exact Device Name>`；
- Tuya：`tuya:<device_id>:<dp_code>`。

名称只用于 Excel 当前映射或用户展示；未来 Tuya 不能用可变设备名称充当稳定身份。

### 2.2 已验证的事实规则

1. 同一文件 SHA 重试直接返回 `duplicate_skipped`，不会产生第二个批次或重复事实；
2. 重叠批次同键同值直接去重；同键不同值保留全部 Source Candidate，并按 `coverageEnd` 较晚、再按 `batchId` 确定规范值；
3. 正常区间使用相邻累计值之差，平均功率使用实际区间时长；
4. gap 和短间隔保留实际时长及能量，但状态为 warning；它们可以进入日级总量，不能伪装成完整 15 分钟覆盖；
5. reset/负差无法可靠推导能量，`usageValue` 为空并标记 invalid；
6. Virtual Meter 按完全一致的区间键对齐输入；缺少任一输入时标记 `incomplete_inputs`，禁止按零补齐；
7. 官方汇总只读取显式 `officialAggregation=true` 的 Meter Point。`Virtual Load 12` 默认 analytical-only，不与 Total Office Load 重复相加。

第 4 条比当前 Python Builder 的“gap 不进入用量”更适合日级分析：有真实前后累计值时，区间总能量仍然成立，只是无法拆成完整的 15 分钟曲线。正式吸收时必须同步修改 Builder 与质量口径，不能让两套逻辑长期并存。

### 3.2 Virtual Load 12

~~~powershell

~~~

结果：


这证明虚拟表可以与同 Scope 的物理表单独分析，但不影响上级官方总量。

### 3.3 边缘场景

~~~powershell
npm run prototype:energy-source-facts -- --demo --view=e
~~~

同一纯函数契约产生：

~~~text
boundary: 2
overlap_conflict: 4
gap: 2
cumulative_reset_or_negative_delta: 2
incomplete_inputs: 2
Virtual incomplete intervals: 2
~~~

SHA 幂等单独复验后，第一次为 `accepted`，第二次为 `duplicate_skipped`，最终 Batch 数仍为 1。

## 4. 问题与取舍

| 问题 | 处理 |
| --- | --- |
| Excel 时间含 `xx:14:59.999` 浮点误差 | Adapter 先按分钟取整，再按 Asia/Singapore 转 UTC |
| 两个导出文件覆盖时间重叠且少量值冲突 | 原始候选全部留存，规范值选择确定且可解释 |
| gap 是否直接丢弃能量 | 不丢弃；保留实际时长和总能量，覆盖率与 15 分钟曲线降级 |
| reset 后不知道真实用量 | 不猜测、不补零，生成 invalid Fact |
| 虚拟表是否参与官方汇总 | 默认不参与；只有未来显式配置为 official component 时才替换输入项 |

原型首次边缘场景运行曾因合成 Source Binding 缺少 `excel:` 前缀而没有生成 Fact；修正夹具后规则正常触发。正式实现应让 Mapping 发布校验阻止这类不匹配。
