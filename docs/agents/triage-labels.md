# Triage Labels

Use this shared vocabulary for GitHub Issues. A ticket may carry one workflow label at a time.

| Label | Meaning | Typical next action |
| --- | --- | --- |
| `needs-triage` | The request exists, but scope, ownership or priority is not yet clear. | Clarify and classify it. |
| `needs-info` | Progress is blocked on missing evidence or a decision from a named source. | Record the exact missing information and who can provide it. |
| `ready-for-agent` | The ticket is sufficiently specified for an agent to execute safely. | Claim it and begin work. |
| `ready-for-human` | The next step requires human judgment, access, approval or physical verification. | Assign or hand off to the responsible person. |
| `wontfix` | The team has deliberately decided not to pursue the ticket. | Record the reason and close it. |

These labels describe triage state. Keep execution state separately in the ticket's `Status` field.
