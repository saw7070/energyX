# EnergyIQ 产品战略与交付路线图

这是面向产品发布会、用户、合作伙伴、投资人和管理团队的 HTML Roadmap 报告。它将原来的 PPT 重新组织为：

1. 一句话产品主张与发布状态；
2. 当前产品价值与交付状态；
3. Preschool / Ngee Ann 客户证明；
4. 15 周整体甘特图与 90 天 Release Gate；
5. 面向发布会的分层技术架构图与产品演进图；
6. Paid Pilot、订阅扩张、Method / SOP 增值的商业模式假设；
7. 下一阶段选择、风险与业务价值衡量指标。

## Files

- `index.html`：可直接打开的单文件 HTML 报告；包含内联 CSS/JavaScript，无构建步骤。
- `EnergyIQ_Product_Strategy_Delivery_Roadmap_2026-08-17.pptx`：原始产品路线图 PPT。
- `EnergyIQ_PMO_Product_Roadmap_2026-08-17.xlsx`：PMO 工作簿。
- `EnergyIQ_PMO_Product_Roadmap_2026-08-17_with_Gantt.xlsx`：带 Gantt 的 PMO 工作簿。

## Editing

打开 `index.html` 后：

- 点击右上角“编辑内容”可直接修改带虚线提示的文字；
- 按 `Ctrl+S` 或点击“下载当前 HTML”保存修改后的独立 HTML；
- 点击“打印 / PDF”可用浏览器生成适合邮件或会议材料的 PDF。

## Status semantics

- **已集成**：代码已经进入 `main`；
- **工程已验证**：自动化或工程检查通过，但不等于客户接受；
- **待人工验收**：需要产品、能源、QA 或客户判断；
- **规划中**：尚未形成可承诺的交付结果。

报告基线：`main`，2026-08-18。路线日期和商业包装是待验证假设，不是客户承诺。
